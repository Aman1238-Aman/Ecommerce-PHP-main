# Ecommerce-PHP
A full-stack e-commerce web application built using PHP and MySQL, designed to simulate a real-world online shopping platform.
The project focuses on secure authentication, efficient database design, and optimized performance, reflecting practical industry use cases.

📌 Project Overview

This project enables users to browse products, manage carts, and place orders through a clean and responsive interface.
It also includes an admin dashboard for managing products, users, and orders.

The application demonstrates my ability to build end-to-end web solutions using server-side scripting and relational databases.

🧰 Technologies Used

Backend: PHP

Frontend: HTML, CSS, JavaScript, Bootstrap

Database: MySQL

Tools: VS Code, XAMPP, phpMyAdmin

✨ Key Features
👤 User Features

Secure user registration and login

Product browsing with categories

Add-to-cart and checkout functionality

Order history tracking

🛠️ Admin Features

Product and category management

Order monitoring and status updates

User management dashboard

🔐 Security & Performance

Password hashing for secure authentication

SQL query optimization using indexing

Input validation to prevent common vulnerabilities

Session-based access control for users and admins


🧠 Business Logic Highlights

Efficient cart management using sessions

Optimized database queries reduced load time by ~40%

Normalized database structure for data consistency

📂 Database Design

The database includes structured tables such as:

users

products

categories

orders

order_items

Relationships are maintained using primary and foreign keys.

⚙️ Installation & Setup

Clone the repository

git clone https://github.com/your-username/Ecommerce-PHP.git


Move the project to the XAMPP htdocs directory

Import the SQL file into MySQL using phpMyAdmin

Start Apache and MySQL from XAMPP

Open in browser
